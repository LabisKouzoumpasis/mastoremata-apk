# Μαστορέματα — κέλυφος Android

Κέλυφος Android (Kotlin, WebView) της εφαρμογής «Μαστορέματα». Οι οθόνες έρχονται από το αποθετήριο
`mastoremata` (`index.html` → `app/src/main/assets/index.html`). Περιγραφή: **CLAUDE.md**.

- Χτίσιμο: αυτόματα από το GitHub Actions σε κάθε push στο `main` → APK στα Releases.
- Τεστ Kotlin: `cd tools/ktest && gradle test`.
